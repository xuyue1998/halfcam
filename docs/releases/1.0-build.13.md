# HALF CAM 1.0 · Build 13

HALF CAM 1.0 的稳定性、性能与五语言文案修复版。
主 App 与实时活动扩展的版本均为 **1.0 (13)**。

本次 GitHub Release 标签为 `v1.0-build.13`，保留既有 `v1.0.0`，不移动或覆盖历史标签。

## 修复与改进

- 修复相机并发启动与预览连接相关崩溃，完善拍摄回调、中断和前后台生命周期处理。
- 原图成功落盘后才增加格数；显影失败保留重试入口，整卷导出不再将部分失败报告为全部成功。
- 加固钥匙串读取、胶卷记录备份／恢复、交易交付与退款处理。
- 限制图像任务并发，复用预览解码，减少重复文件读取，并补充性能标记与基准测试。
- 复核简中、繁中、英文、日文与韩文文案，明确卸卷、显影、自动导出、权限、购买与恢复提示。
- 更新本地隐私说明及商店草稿；Release 不提供 Debug 动态光圈实验入口。

## 已完成的验证

- **80 项自动检查通过**，包含源码守卫与隔离运行回归测试；不等同于 80 项真机测试。
- **232 条活跃文案、五种语言**的完整性、占位符和引用校验通过。
- iOS Simulator / arm64 / Debug 构建、Xcode 静态分析及 iOS / Release 未签名归档通过。
- 归档内文案与源码一致，43 个引擎／许可／隐私文件比对通过；主 App 与扩展的 dSYM UUID 分别匹配。

详细范围与限制见 `docs/PRE-RELEASE-CHECK.md`、`docs/COPY.md` 和 `docs/PERFORMANCE.md`。
性能结果是 macOS 微基准，不是 iPhone 冷启动、帧率或内存峰值测试。

## 下载与构建

**此 Release 发布源码，不包含 IPA 安装包，不代表已上传 TestFlight 或已在 App Store 上架。**
需要 iOS 17 或更高版本；构建与引擎准备方法见仓库 `README.md` 和 `SPEKTRA.md`。

真机完整流程、72 格压力测试、StoreKit 沙盒、多设备同步、五语言排版及辅助功能仍需验收。
正式分发前还需完成分发签名、出口合规回答与 App Store Connect 验证。
