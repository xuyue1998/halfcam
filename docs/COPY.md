# HALF CAM 文案规范与清单

## 语气

像胶片机上的说明：简短、克制、有实体感。保留装卷、过片、倒片、显影的仪式，不让用户猜操作。

- 按钮说动作，状态说进度，说明说结果。不要为了复古感创造难懂的操作词。
- 空状态可以有温度；删除、权限、订阅、购买说明必须明确，不用隐喻。
- 不使用“才配打开”“快门是死的”“清掉”等带评判或容易误解的表述。
- 不承诺瞬间完成显影、不将虚拟机身说成真实硬件、不宣称胶片会自动云备份。

源码中的中文字符串保留为稳定引用键，**显示文字以 `stringUnit.value` 为准**。例如 `L("倒出这卷")` 显示“导出整卷”。修改文案时请同步五种语言，保留 `%lld`、`%@` 的参数编号与类型。

已有明确的按钮、计数、摄影术语保持不变。无引用的历史 `stale` 项保留供比对，不当作当前界面，不批量删除。仍在使用的动态胶片简介改为 `manual`，避免提取时被误删。

## 完整五语言清单与校验

```sh
python3 scripts/check_copy.py
python3 scripts/check_copy.py --inventory
python3 -m doctest scripts/check_copy.py
python3 -m unittest discover -s scripts -p test_check_copy.py
```

`--inventory` 只输出 Markdown，不修改任何文件。清单逐条列出三个文案表中全部有效说明与对应五语言译文，排除铭牌符号、纯数字格式及无引用的历史项。以运行时文案表为单一来源，避免另存一份文案后失去同步。

校验包括缺失翻译、重复 JSON 键、源码 `L()` 引用注册、动态参数类型和序号、旧导出术语、动态简介注册以及 StoreKit 语言覆盖。源码引用检查支持当前使用的嵌套插值，不是完整 Swift 语法解析器；编译仍是必要检查。

## 必须准确的说明

- 免费：每月 3 卷、每卷最多 12 格、每月赠 1 张加急券。
- 年卡：每月 9 卷、每卷最多 36 格、每月赠 3 张加急券，按年自动续订。
- 买断：不限装卷、每卷最多 72 格、每月赠 6 张加急券，一次性购买。
- 加急券跳过一卷的等待，不跳过实际图像处理。每月赠券次月初失效；购买券不过期，开启 iCloud 后可同步余量。
- 等待结束通知使用“可取件”，不提前宣称成片已生成。
- 切换语言时，同时更新现有的待发送通知文案，不重新申请通知权限、不延长原定等待。
- 待导出数量按最终照片“张”计数，对页两格合为一张，不标成底片“格”。
- 删除 App 会删除其中全部胶片，已保存到系统相册的副本不受影响。iCloud 同步加急券余量，不代表备份照片。
- 仅在主动导出或开启自动导出后保存到系统相册。

法律条文、第三方许可证、引擎文档、内部日志不做品牌化重写。截图中文字需要重新生成图层；本轮不覆盖已有图片、实机截图或其他任务中的商店图脚本。
