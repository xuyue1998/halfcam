## 本轮修复

| 范围 | 修复内容 |
|---|---|
| 拍摄落盘 | 等待原图原子写入成功后才增加格数；失败不消耗格数，提示重试。拍摄关联原胶卷 ID，拍摄期间阻止装卷、卸卷、过片、倒片和测试重置。 |
| 拍摄回调 | 用 photo settings 的 unique ID 区分请求，忽略旧请求和重复回调；处理完图像后等待终结回调再恢复 continuation，增加 60 秒兜底，停止/中断时解除等待。 |
| 相机生命周期 | 记录是否仍需要运行，防止授权回调在退后台后重新启动相机；处理相机中断结束和媒体服务重置，取消无效的拍摄等待。 |
| ProRAW | 拍摄过程中延后切换输出配置，拍摄终结后再应用；保留启动前提出的 RAW 设置请求。 |
| 真实设备 | 无相机或相机不可用时，不再把模拟器生成的图片当作真实照片保存。模拟器图片固定 1× 绘图。 |
| 光谱引擎 | 初始化、预热和渲染使用同一锁；解码也进入串行区间，避免多个等待任务提前分配完整浮点图像；渲染临时对象使用 autorelease pool。 |
| 图像边界 | 在整数转换和分配前校验有限尺寸、像素总量、结果 stride；正确处理非零 startIndex 的 Data 切片；拒绝无效 EXIF 数值，不再把对焦位置误写为光圈值。 |
| 显影失败 | 不再用缩略图冒充完整输出，不再无条件把进度设为 100%；保留底片，显示重试/合上入口，阻止未完成的胶卷被标成 ready。 |
| 显影队列 | 避免正在处理的胶卷重复入队；迭代消费队列，按稳定的 frame UUID 更新结果，不跨 await 复用数组下标；校验既有成片文件。 |
| 整卷导出 | 每生成一批即保存并释放该批 JPEG，不再先持有整卷成片；图片缺失/合成失败不再被当作成功，部分批次失败不会伪报全部成功。 |
| 相册状态 | 有限照片权限下不把不可见资源判为已删除；不为自动核对弹权限请求；保留核对期间新产生的导出 ID；对页状态使用共同 asset ID 判断。 |
| 任务取消 | 等待导出锁或等待拍摄结束的循环正确退出取消任务，避免取消后的 sleep 形成忙循环；旧视图任务不再写入新视图的图片状态。 |
| 缓存与样片 | 缓存任务使用不会因 purge 重置的 generation，取消失效工作；样片后台降采样，不在 SwiftUI body 中同步加载全尺寸图片。 |
| 钥匙串 | 读取失败不再删除/替换旧密钥；只在确实不存在时创建，序列化生成流程，检查保存结果；重复创建时使用已存储的赢家密钥。 |
| 元数据持久化 | 增加上一份有效库索引备份；主索引损坏时尝试备份，两份都不可读时禁止空数据覆盖；跳过内容未变化的写入，写失败提示，退后台立即刷新待保存设置。 |
| StoreKit | 购买、恢复和刷新防重复进入；挂起的负数退款回调也能交付；先交付未完成交易再导入历史 ID；不再截断退款 ID，避免老退款被重新视为有效交易。 |
| 通知与语言 | 通知代理回调使用 nonisolated，避免跨 actor 传递系统通知对象；冷启动通知先挂起再交给 model；新增错误/重试文案覆盖五种语言。 |
| 分发接口 | 动态光圈实验只在 Debug 编译。Release 使用公开的硬件光圈读数，不提供动态调节入口；分发二进制不包含四个相关非公开 selector 字符串。 |
